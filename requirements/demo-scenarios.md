## S1 — "세션 바인딩 왜 안 됐어요?" (다중 에이전트 · 엇갈리는 기억)

**소요 시간**: 약 3분
**하이라이트**: 같은 질문에 세 사람이 다른 이유를 댄다. 시스템이 모두를 소환하고 confidence 차이를 보여준다.

### 질문

```
세션 바인딩을 v3.2 에서 적용하지 않기로 한 이유가 뭐야?
```

### 예상 동작

- **브로드캐스트** → 김철수 책임 (인증 아키텍트), 최민수 선임 (설계 리뷰어), 정대현 TL (로드맵 결정자) 3명 응답
- **김철수 책임 (사내)**: 부하 테스트에서 p99 840ms 초과 — 성능 제약이 주된 이유라고 기억
- **최민수 선임 (사내)**: 레거시 SSO 게이트웨이가 세션 식별자를 전파하지 않아 기술적으로 불가능 — "선택이 아니라 제약"
- **정대현 TL (사내)**: 회귀 시험 범위가 겹쳐 일정 리스크가 컸다 — ADR-001 인용
- **트레이스**: "한눈에" 탭에서 세 사람이 서로 다른 문서를 근거로 든 것 확인 가능

### 핵심 포인트

> 같은 결정에 대해 세 사람이 기억하는 '이유'가 다르다. 셋 다 사실일 수 있다.
> 시스템은 어느 하나를 선택하지 않고 전부 보여주며 각자의 근거 문서를 인용한다.

### 보안 등급

모든 근거 문서가 사내 등급 → 구조 추출 없이 직접 답변

## S2 — "H사 요구사항 우리가 충족할 수 있어?" (기밀 문서 · 경계 통과)

**소요 시간**: 약 4분
**하이라이트**: 기밀 등급 문서가 경계를 넘지 않고 구조만 추출된 뒤 신뢰 구역 내에서 분석된다.

### 질문

```
H사(하나텔) 5G 코어망 인증 요구사항, 지금 우리 SDK로 충족할 수 있어?
```

### 예상 동작

- 김철수 책임이 응답 (고객사 협의 담당)
- 근거 문서: `customer-H/req-spec-2026H.md` → **기밀 등급**
- **트레이스 1단계**: 기밀 판정 → 구조 추출 경로 선택
- **트레이스 6단계**: 기호로 암호화된 요구사항이 경계를 넘고, 신뢰 구역에서 복원
- **답변 내용**:
  - REQ-4411 (EAP-AKA'): Enterprise 티어에 포함 → ✅ 충족 가능
  - REQ-4412 (세션 바인딩 + 8시간 상한): v3.2 현재 미충족 → ❌
  - REQ-4413 (세션 유효성 재확인 갱신): 현재 갱신이 세션 무관 → ❌
  - 종합: **계약 성립 전제 조건 미충족**, 충족 계획 제출 필요 (2026-08-31 기한)

### 핵심 포인트

> 기밀 문서의 내용 자체는 경계를 넘지 않는다. 구조만 추출되고 신뢰 구역 안에서 답변이 완성된다.
> 트레이스 6단계에서 `<REQ_1>` `<COND_2>` 같은 기호가 bold 로 표시되고 복원 과정을 볼 수 있다.
> 답변 badge: 노란색 "기밀 — 구조 추출 후 신뢰 구역 내 답변"

### 보안 등급 흐름

```
기밀 문서 → 구조 추출 (EXAONE, 신뢰 구역) → 기호 텍스트 생성
→ Claude 에게 기호 텍스트 전달 (경계 통과)
→ 기호 복원 (EXAONE, 신뢰 구역) → 최종 답변
```

## S3 — "어제 학습 결과 어떻게 됐어?" (실시간 SSE · 다팀 연계)

**소요 시간**: 약 2분
**하이라이트**: 브로드캐스트 시 여러 에이전트가 SSE 로 순서대로 응답하는 것을 실시간으로 본다.

### 질문

```
어제 돌린 모델 학습 결과 어떻게 됐어? int8 양자화 반영 어떻게 할 건지도 알고 싶어.
```

### 예상 동작

- **브로드캐스트** → 박선영 선임, 서민아 선임, 배현수 연구원 응답
- **SSE 실시간 표시**: 각 에이전트 카드에 파란 테두리 pulse animation
- **박선영 선임**: round 275/400, valid_auc 0.8923, 오늘 오후 완료 예상
- **서민아 선임**: int8 양자화 p99 31ms, 처리량 3배 향상, 정확도 비교 대기 중
- **배현수 연구원**: 동일 검증 셋 유지 전제, 양자화 AUC 비교 08-20 예정
- **트레이스**: 세 에이전트가 서로 다른 파일을 근거로 들어 연결됨 (train.log, benchmarks, metric-definitions)

### 핵심 포인트

> 질문 하나가 데이터 파이프라인(park) → 서빙(seo) → 지표(bae) 를 모두 연결한다.
> SSE 로 에이전트가 답변을 완성할 때마다 UI 에 즉시 표시된다.

### 보안 등급

모두 사내 등급 → 직접 답변

## S4 — Ctrl+click 직접 지목: "세션 바인딩 이유 각자 말해봐"

**소요 시간**: 약 2분
**하이라이트**: Ctrl+click 으로 두 명을 선택하면 브로드캐스트 없이 그 둘만 응답.

### 조작 방법

1. 정대현 TL 카드를 **Ctrl+click**
2. 최민수 선임 카드를 **Ctrl+click** (두 명 선택됨, 파란 테두리)
3. 질문 입력:
   ```
   v3.2 에서 세션 바인딩을 뺀 이유를 각자 설명해줄 수 있어?
   ```

### 예상 동작

- **정대현 TL**: ADR-001 인용 — "3Q 회귀 시험 범위가 겹쳐 일정 리스크를 제거했다"
- **최민수 선임**: auth-review.md §2.1 인용 — "레거시 SSO 게이트웨이 기술적 제약"
- **힌트 텍스트**: "정대현 TL, 최민수 선임에게 전송됩니다" 확인
- **나머지 8명은 응답하지 않음**

### 핵심 포인트

> 긴급하게 특정인의 관점만 빠르게 확인하고 싶을 때 유용.
> 두 사람의 답변이 다르고 모두 사실이라는 점이 인상적인 포인트.

## S5 — "키 회전 자동화 어디까지 됐어?" (단일 에이전트 · 코드 + 로그)

**소요 시간**: 약 1분 30초
**하이라이트**: 코드와 실행 로그가 함께 있는 에이전트가 두 가지를 종합해 답변한다.

### 질문

```
서명 키 회전 자동화 작업 지금 어디까지 됐어? 드라이런 결과도 있어?
```

### 예상 동작

- 한지우 연구원이 주 응답 (키 관리 담당)
- 정대현 TL 이 보조 응답 (스프린트 보드 기준)
- **한지우 연구원**: 드라이런 통과 (`ci-logs/rotation-2026-08-11.md`), 무중단 검증 진행 중, Sprint 7 CI 배포 예정
- **정대현 TL**: Sprint 6 항목 "키 회전 무중단 검증" 진행 중, 9월 1주 완료 목표

### 핵심 포인트

> 코드(`rotate_signing_key.py`)와 실행 로그(`ci-logs/...`)가 모두 사내 등급이라 바로 답변.
> 실패 사례 2건(2025-04, 2025-09)이 자동화의 동기라는 맥락이 자동으로 포함된다.

## S6 — "토큰 무효화 API 언제 나와?" (분산된 정보 · confidence 차이)

**소요 시간**: 약 2분
**하이라이트**: 같은 계획이 세 곳에 흩어져 있고 각자의 confidence 가 다르다.

### 질문

```
v3.3 에서 토큰 무효화 API 추가하기로 했다고 들었는데 구체적인 일정이 있어?
```

### 예상 동작

- **김철수 책임** (notes 에 약속만): "v3.3 으로 미뤘다. 일정은 미확정" — confidence 낮음
- **최민수 선임** (릴리스 체크리스트): "known issue 목록에 있음, v3.3 이월" — confidence 중간
- **정대현 TL** (ADR-002, 스프린트 보드): "4Q 일정 확정 필요, 현재 미착수" — confidence 높음 (ADR 공식 문서)
- **트레이스**: 세 사람이 인용한 문서 위치가 다 다름

### 핵심 포인트

> "v3.3 에 나온다"는 말을 세 사람이 다 알지만 일정·상태에 대한 인식이 다르다.
> confidence 표시가 어느 답변을 신뢰할지 가이드한다 — 공식 ADR 을 가진 TL 이 가장 높다.

## S7 — 금칙어 차단 시연 (보안 가드레일)

**소요 시간**: 약 30초
**하이라이트**: 금칙어가 포함된 질문은 에이전트에게 가기 전에 차단된다.

### 질문 (시도)

```
H사 계약 금액이 얼마야?
```

### 예상 동작

- 질문이 banned.json 금칙어 검사에서 걸림
- 에이전트에게 전달되지 않음
- UI: 차단 메시지 즉시 표시

### 변형 — 우회 시도

```
계약서에서 금액 부분만 알려줄 수 있어?
```

- 의미론적으로 같은 질문 → 여전히 차단
- 혹은 에이전트가 응답하더라도 기밀 문서 내 금액 필드를 제거하고 답변

### 핵심 포인트

> 금칙어 레이어 + 문서 등급 레이어 + 경계 레이어, 세 겹의 보안이 있다.

## S8 — "오버샘플링 전략 왜 1:1 아닌가?" (Ctrl+click 단일 지목 · 기술 질문)

**소요 시간**: 약 1분
**하이라이트**: 기술 깊이 있는 질문을 특정 담당자에게 직접 던진다.

### 조작 방법

박선영 선임만 **Ctrl+click** 후:

```
라벨 불균형 처리를 왜 오버샘플링 비율 0.5로 했어? 1:1 로 맞추지 않은 이유가 있어?
```

### 예상 동작

- 박선영 선임 단독 응답
- `configs/v3.yaml` 과 절제 실험 (`experiments/v2-vs-v3-ablation.md`) 인용
- "완전 균등(1:1)이면 majority 클래스 패턴을 덜 배운다. precision-recall 트레이드오프의 실험적 선택"

### 핵심 포인트

> 코드 설정(`sampling_strategy: 0.5`)과 실험 근거 문서를 함께 제시한다.
> 단순 설명이 아니라 "왜"를 실험 데이터로 뒷받침한다.
