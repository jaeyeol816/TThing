# 평가 지표 정의

## 1. 문제

실험마다 검증 셋이 달라 **숫자를 비교할 수 없었다.** 0.82 와 0.79 중
어느 쪽이 나은지 말할 수 없는 상태였다.

## 2. 해결

검증 셋을 고정한다. 고정 셋의 해시를 실험 기록에 함께 남기고, 해시가
다르면 **비교 자체를 막는다.**

## 3. 지표

| 지표 | 정의 | 주의 |
|---|---|---|
| macro-F1 | 클래스별 F1 의 단순 평균 | 소수 클래스가 결과를 지배한다 |
| micro-F1 | 전체 TP/FP/FN 합산 | 다수 클래스가 결과를 지배한다 |
| PR-AUC | 정밀도-재현율 곡선 아래 면적 | 불균형에서 ROC-AUC 보다 정직하다 |

라벨 불균형이 있는 문제에서 **ROC-AUC 를 주지표로 쓰지 않는다.**
음성이 압도적으로 많으면 ROC-AUC 는 쉽게 높아진다.

## 4. 재현 규칙

실험 기록에 아래가 없으면 그 숫자는 인용하지 않는다.

- 검증 셋 해시
- 시드
- 전처리 버전

셋 중 하나라도 없으면 "재현되지 않은 결과"로 표시한다.
