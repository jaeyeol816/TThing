# 평가 지표 정의

## 원칙

**지표는 검증 셋이 다르면 비교할 수 없다.**
이 문서의 모든 지표는 특정 검증 셋과 결합해서만 의미가 있다.
수치만 인용하면 오해가 생긴다. 셋을 반드시 함께 밝힌다.

## 주요 지표

### AUC (Area Under ROC Curve)

**용도**: 임계값 독립적인 판별력 측정.
**범위**: 0.5 (무작위) ~ 1.0 (완벽).
**현행 기준선**: val_v3_std 기준 v2 모델 0.8741.

AUC 는 클래스 불균형에 비교적 강인하다. 그러나 클래스 1 의 정밀도-재현율
트레이드오프는 이걸로 보이지 않는다.

### Recall (Sensitivity) @ 클래스 1

**용도**: 실제 양성(클래스 1) 중 몇 개를 잡았는지.
**현행 목표**: 0.70 이상.

이 데이터셋에서 클래스 1 을 놓치는 비용이 크다. Recall 이 AUC 와 함께
주요 지표로 보고된다.

### Precision @ 클래스 1

**용도**: 클래스 1 로 예측한 것 중 실제 양성 비율.
**현재 추적 여부**: Recall 과 함께 보고하나 임계값 의존성이 크다.
임계값을 0.5 로 고정한 값으로 보고한다.
