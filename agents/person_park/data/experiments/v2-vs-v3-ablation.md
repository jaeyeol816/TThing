# v3 vs v2 전처리 절제 실험

**목적**: v3 전처리에서 무엇이 성능 향상에 기여했는지 분리 확인

---

## 1. 실험 설계

v2 → v3 전처리 변경 사항 4가지를 하나씩 추가하는 절제 실험.

| 실험 ID | 변경 사항 | 누적 |
|---|---|---|
| A (기준선) | v2 그대로 | — |
| B | 파생 피처 3개 추가 (bucket, ratio, hour) | +B |
| C | 결측 처리 그룹 기준 변경 | +B+C |
| D | 오버샘플링 0.3 → 0.5 | +B+C+D |
| E (v3 최종) | class_weight=balanced_subsample 추가 | +B+C+D+E |

---

## 2. 결과

모두 동일 검증 셋 · 동일 모델 하이퍼파라미터.

| 실험 | valid_auc | valid_recall | 비고 |
|---|---|---|---|
| A (v2 기준선) | 0.8741 | 0.6832 | |
| B | 0.8783 | 0.6901 | 파생 피처 효과 |
| C | 0.8801 | 0.6988 | 결측 처리 개선 소폭 |
| D | 0.8862 | **0.7311** | **recall 큰 폭 개선** |
| E (v3) | 0.8898 | 0.7419 | |

---

## 3. 해석

**D(오버샘플링 0.5)가 recall 향상의 주된 원인**이다. 0.3 → 0.5 한 스텝만으로
recall 이 0.069 올랐다.

파생 피처(B)는 AUC 에 기여하지만 recall 에는 작게 기여한다.
class_weight(E)는 D 위에서 추가 효과가 작다 — D 가 이미 클래스 불균형을
많이 해소했기 때문.

---

## 4. 한계

- 이 실험은 `preproc_v2/` 기반 데이터로 했다. `preproc_v3/` (현재 학습 중)는
  데이터 양이 더 많고 피처 87개다. 결과가 다를 수 있다.
- 검증 셋이 바뀌면 절대 수치는 비교 불가 (배현수 연구원 지침 참조).

---

## 5. 결론

오버샘플링 전략이 이 데이터셋에서 가장 효과적인 레버이다.
다음 실험에서는 1.0 (완전 균등)과 0.7 도 비교할 것.
단, 검증 셋을 바꾸면 기존 결과와 비교가 안 되므로 셋은 고정한다.
