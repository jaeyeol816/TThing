# 서빙 튜닝 노트

## 1. 지금 재고 있는 것

추론 지연을 줄이기 위해 **배치 크기**와 **양자화**를 조합해 시험 중이다.
아래 수치는 전부 **시험 환경**이며 운영 환경 수치가 아니다.

## 2. 시험 조건 (이걸 빼면 수치가 의미 없다)

- 입력 길이 고정 (512 토큰)
- 동시 요청 8
- 워밍업 후 5분 구간 측정
- 단일 GPU, 다른 작업 없음

## 3. 관측

| 배치 | 양자화 | 상대 지연 | 상대 처리량 |
|---|---|---|---|
| 1 | 없음 | 1.00 | 1.00 |
| 4 | 없음 | 1.35 | 2.90 |
| 4 | 8bit | 1.05 | 3.30 |
| 8 | 8bit | 1.60 | 4.10 |

배치 4 + 8bit 가 지연을 거의 늘리지 않으면서 처리량을 3배 이상 올린다.
배치 8 부터는 지연 증가가 눈에 띈다.

## 4. 아직 말할 수 없는 것

- 운영 환경 수치. 입력 길이 분포가 다르고 동시 요청이 변동한다.
- 양자화가 품질에 주는 영향. 평가 담당의 지표 확인이 필요하다.

수치를 인용할 때 **조건을 함께** 적을 것. 조건 없는 수치는 오해를 만든다.
