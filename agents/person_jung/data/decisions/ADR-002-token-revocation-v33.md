# ADR-002: v3.3 토큰 무효화 API 추가

## 상태

**Accepted** — 2025-12 설계 리뷰 조건부 승인의 후속 확정

## 맥락

SDK v3.2 설계 리뷰(2025-12-03, 최민수 선임)에서 토큰 수명 24시간 승인의
조건으로 **v3.3 에 토큰 무효화 API 추가**가 명시됐다.

무효화 API 부재의 현재 영향:

- 자격증명 탈취 시 만료까지 최대 24시간 대기
- 롤백 시 발급된 토큰을 즉시 회수 불가 (최대 24시간 대기)
- 레거시 SSO 로그아웃이 토큰에 전파되지 않음

이 약속이 2026-08 현재까지 이행되지 않았다. v3.3 일정이 정해지지 않은 것이
원인이다. (출처: `person_kim/data/notes/2025-11-auth.md`)

## 결정

v3.3 에 `/revoke` 엔드포인트를 추가한다.

- RFC 7009(Token Revocation) 준수
- 액세스 토큰 + 리프레시 토큰 모두 지원
- 감사 로그 기록 (누가 언제 무효화했는지)

## 제약

구현보다 **연동 상대 합의가 더 오래 걸린다.** SDK 소비 측이 무효화를
호출하는 시나리오를 정의하고 합의해야 한다.

## 이 결정이 없으면

- 세션 바인딩(ADR-001)을 4Q 이후로 계속 미룰 수밖에 없다
- 24시간 토큰 수명에 대한 보안팀 조건이 계속 미이행 상태로 남는다
