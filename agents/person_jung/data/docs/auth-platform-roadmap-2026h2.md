# 인증 플랫폼 2026 하반기 로드맵

## 1. 이번 반기의 판단 기준

두 가지를 동시에 하지 않는다. **인증 방식 변경**과 **연동 범위 확대**는
회귀 시험 비용이 서로 곱해지므로 분기를 나눈다.

## 2. 분기별 배치

| 분기 | 항목 | 상태 | 비고 |
|---|---|---|---|
| 3Q | SDK v3.2 릴리스 안정화 | 진행 | 릴리스 담당이 회귀 시험 주관 |
| 3Q | 서명 키 회전 자동화 | 진행 | 수동 절차 제거가 목표 |
| 4Q | 세션 바인딩 도입 검토 | 대기 | 3Q 안정화 완료가 선행 조건 |
| 4Q | 외부 IdP 연동 범위 확대 | 대기 | 백채널 로그아웃 검증 후 판단 |

## 3. 세션 바인딩을 4Q 로 미룬 이유

설계 리뷰에서 제기된 것은 "안 한다"가 아니라 **"지금은 아니다"** 였다.
근거는 세 가지다.

1. 클라이언트 재발급 경로가 아직 한 곳으로 모이지 않았다. 바인딩을 넣으면
   재발급 실패가 여러 경로에서 서로 다른 증상으로 나타난다.
2. 회귀 시험 범위가 릴리스 안정화와 겹친다. 같은 분기에 두면 실패 원인을
   가릴 수 없다.
3. 도입 자체의 난이도보다 **되돌리는 비용**이 크다. 되돌릴 수 있는 시점에
   넣어야 한다.

## 4. 우선순위가 바뀌는 조건

아래 중 하나라도 발생하면 4Q 항목을 3Q 로 당긴다.

- 토큰 재사용 사고가 실제로 관측된 경우
- 연동 상대측 규격이 세션 바인딩을 요구로 못 박은 경우

## 5. 이 문서의 한계

일정은 시점에 따라 바뀐다. 이 문서는 2026-08-19 기준이며, 확정이 아니라
**현재의 판단**이다. 인용할 때 시점을 반드시 함께 밝힐 것.
