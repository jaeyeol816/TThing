# 데이터 보존 정책

## 1. 보존 기간

| 종류 | 보존 | 근거 |
|---|---|---|
| 원본 로그 | 90일 | 장애 분석에 필요한 최대 구간 |
| 파생 피처 | 180일 | 재학습 재현에 필요 |
| 학습 산출물 (체크포인트) | 2개 세대 | 롤백 대상만 |
| 실험 로그 | 무기한 | 용량이 작고 재현성의 근거다 |

## 2. 삭제가 아니라 만료다

기간이 지난 데이터는 자동 만료된다. 사람이 지우는 절차를 두지 않는다 —
지우는 절차는 잊히고, 잊히면 보존 정책이 문서에만 존재하게 된다.

## 3. 파생 데이터의 만료

원본이 만료돼도 파생 피처는 자기 기간을 따른다. 다만 **등급은 계속
원본을 따른다** — 원본이 사라졌다고 파생의 등급이 내려가지 않는다.

## 4. 예외

법적 보존 요구가 있으면 만료를 멈춘다. 그 결정은 문서로 남기고,
멈춘 이유가 해소되면 다시 켠다.
