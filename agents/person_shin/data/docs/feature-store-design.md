# 피처 스토어 설계

## 1. 구조

    원본 로그  →  전처리  →  피처 테이블  →  (학습 / 서빙)

피처 테이블은 학습과 서빙이 **같은 것을 읽는다.** 두 경로가 다른 계산을 하면
학습-서빙 편차가 생기고, 그 편차는 지표로 잘 드러나지 않는다.

## 2. 등급 승계 규칙

피처의 보안 등급은 **원본의 최고 등급**을 따른다.

    피처 등급 = max(원본1 등급, 원본2 등급, ...)

집계·익명화했다는 이유로 낮추지 않는다. 낮추려면 별도 검토를 거치고
그 결정을 문서에 남긴다. 검토 없이 낮춘 피처는 사용을 막는다.

## 3. 왜 max 인가

두 원본을 합친 피처는 각각으로는 알 수 없던 것을 알려줄 수 있다.
"둘 다 사내 등급이면 합쳐도 사내" 는 성립하지 않는 경우가 있다.
낮게 잡은 실수는 유출이고 높게 잡은 실수는 불편이다.

## 4. 시점 정합성

학습 시점에 존재하지 않았던 정보가 피처에 들어가면 누수다.
피처 테이블은 이벤트 시각 기준으로 잘라 읽는다 (point-in-time).
