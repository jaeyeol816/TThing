# 3Q 스키마 동결 결정

## 배경

데이터 계약 v2 가 확정된 직후 실험팀에서 피처 추가 요청이 들어왔다.
v3 학습 주기(Sprint 6) 와 겹치는 시점이어서 파괴적 변경은 불가하다는 판단을 내렸다.

## 결정

**2026-08-12 ~ 2026-09-05 기간 동안 `data/preproc_v3/` 스키마를 동결한다.**

- 이 기간 내 추가(Add 등급) 변경만 허용
- 완화·파괴 등급 변경은 Sprint 7 이후로 이월
- 예외가 필요하면 데이터플랫폼팀 리더 승인 필요

## 근거

학습 런이 진행 중(2026-08-19 현재 round 275/400)이다. 스키마가 바뀌면
진행 중인 런이 무효화되고 재시작해야 한다. A100 GPU 시간이 낭비된다.

피처 스토어 구조상, 스키마 변경은 학습 + 서빙 양쪽에 동시 영향을 준다
(신동욱 책임의 피처 스토어 설계 §1 참조 — 학습과 서빙이 같은 테이블을 읽는다).

## 요청된 피처 추가 건 처리

| 요청자 | 피처 | 처리 |
|---|---|---|
| 배현수 연구원 | `auth_method_encoded` | Sprint 7 이후 |
| 서민아 선임 | `session_geo_region` | Sprint 7 이후 |

두 건 모두 파괴 등급이 아닌 추가 등급이지만, 추가가 진행 중인 학습 런의
재현성에 영향을 줄 수 있어 이월한다.
