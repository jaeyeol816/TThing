# 토큰 수명 정책

## 1. 현행 값

| 토큰 | 수명 | 갱신 |
|---|---|---|
| 액세스 토큰 | 15분 | 리프레시로 재발급 |
| 리프레시 토큰 | 14일 | 사용 시 회전 (rotating) |
| ID 토큰 | 15분 | 재발급 없음 |

## 2. 리프레시 토큰 회전

한 번 쓴 리프레시 토큰은 즉시 폐기하고 새 것을 준다. 폐기된 토큰이 다시
오면 **그 계정의 리프레시 계열 전체를 무효화**한다 — 탈취 신호로 본다.

이 규칙의 부작용: 네트워크 재시도로 같은 리프레시 토큰이 두 번 나가면
정상 사용자도 로그아웃된다. SDK 쪽에서 재시도를 멱등하게 처리해야 한다.

## 3. 액세스 토큰 15분의 근거

수명을 줄이면 무효화 지연이 짧아지고 갱신 트래픽이 늘어난다. 15분은
그 둘의 절충이며, 근거는 갱신 트래픽 측정치다 — 수명을 5분으로 줄였을 때
갱신 요청이 약 3배가 됐다.

## 4. 바꾸려면

수명 변경은 **연동 상대와 합의가 필요하다.** 일방적으로 줄이면 상대측
캐시 전제가 깨진다.
