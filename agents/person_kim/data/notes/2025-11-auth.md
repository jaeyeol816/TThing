## 11/07 — 토큰 수명 24시간으로 왜 늘렸나

기록 안 해두면 또 물어볼 것 같아서 적어둔다.

v2.x 는 4시간이었다. 근데 모바일에서 재인증 빈도가 너무 높았고,
프로덕트 쪽에서 이탈률 데이터를 들고 왔다. 4시간 만료 직후 이탈이 튀는 게
보였다. 정확한 수치는 프로덕트 대시보드에.

그래서 24시간 + 백그라운드 무음 갱신으로 가기로 했다.
보안팀은 "무효화 경로 없이 24시간은 길다"고 했는데, 무효화 API 를
v3.3 으로 미루는 조건으로 합의했다. 그 약속 아직 안 지켰다.

## 11/14 — 세션 바인딩 왜 빼기로 했나

부하 테스트 돌렸다. 동시 인증 3천 TPS 구간에서 세션 조회 지연이
임계를 넘었다. 세션 스토어를 한 번 더 왕복하는 게 생각보다 비쌌다.

p99 가 목표를 못 맞췄고, 그 시점에 릴리스 일정이 3주 남아 있었다.
세션 바인딩은 일단 빼기로 했다.

수치는 고객 환경 벤치마크 문서에 있다. (권한 필요)

캐시를 앞에 두는 방법도 논의했는데, 캐시 무효화가 결국 같은 문제를
만든다는 결론이었다. 근본적으로는 세션 스토어 자체를 바꿔야 한다.

> 최민수가 리뷰에서 다른 이유를 적었던 것 같은데 확인 안 해봤다.
> 아마 SSO 쪽 얘기였을 것. 둘 다 걸렸던 걸로 기억한다.
