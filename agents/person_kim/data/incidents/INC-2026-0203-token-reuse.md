# INC-2026-0203: 토큰 재사용 의심 사고

## 1. 개요

| 항목 | 내용 |
|---|---|
| 발생 | 2026-02-03 11:42 KST |
| 탐지 | 2026-02-03 11:58 KST (이상 감지 알람) |
| 종결 | 2026-02-03 14:20 KST |
| 영향 | 계정 1건 (내부 테스트 계정) |
| 심각도 | P2 — 실 사용자 영향 없음, 패턴 추적 필요 |

## 2. 사고 경위

11:42: 내부 테스트 계정에서 **동일 액세스 토큰을 서로 다른 IP 두 곳에서 동시 사용**하는
패턴이 이상 감지 알람에 걸렸다.

IP A (서울 리전 내부망) + IP B (알 수 없는 외부망) 동시 인증.

11:58: 알람 검토 → 테스트 계정이라 즉시 차단하지 않고 관찰 진행.

12:30: IP B 에서 10회 추가 호출. 토큰은 22시간 잔여 수명.

13:15: 수동으로 토큰 세션을 만료 처리 (DB 직접 수정 — 정식 API 없음).

14:20: IP B 호출 중단 확인. 사고 종결.

## 3. 근본 원인

**토큰 무효화 API 부재**가 직접 원인이다.

탐지는 됐으나 즉각 차단 수단이 없었다. DB 직접 수정이라는 임시 방편을 써야 했다.

세션 바인딩이 있었다면 IP B 에서의 토큰 사용이 처음부터 거부됐을 것이다.
그러나 현재 세션 바인딩이 적용되지 않는다(ADR-001).

## 4. 재발 방지

| 항목 | 담당 | 기한 | 상태 |
|---|---|---|---|
| 토큰 무효화 API (v3.3) | 김철수 책임 | v3.3 배포 시 | 🔴 미착수 |
| 이상 감지 → 자동 차단 연동 | 김철수 책임 | v3.3 배포 시 | 🔴 미착수 |
| DB 직접 수정 절차 문서화 (임시) | 한지우 연구원 | 2026-03 | ✅ 완료 |

## 5. 참고

이 사고는 ADR-001(세션 바인딩 이월), ADR-002(무효화 API v3.3) 결정의
근거 데이터 중 하나다.

정대현 TL: "실 사용자 영향이 없었지만, 다음에는 없다는 보장이 없다."
