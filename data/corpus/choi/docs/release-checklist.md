# SDK v3.2 릴리스 체크리스트

배포 파이프라인 담당: 최민수 선임

## 1. 사전 확인

- [x] 단위 테스트 전체 통과
- [x] 통합 테스트 (Nova 게이트웨이 경유)
- [ ] 통합 테스트 (레거시 SSO 경유) — 클레임 매핑 이슈로 2건 실패
- [x] 성능 회귀 테스트
- [ ] 보안 스캔 (의존성 취약점 1건 검토 중)

## 2. 빌드

```
make release VERSION=3.2.0
```

산출물: `dist/sdk-core-3.2.0.tar.gz`, 컨테이너 이미지 `sdk-core:3.2.0`

## 3. 스테이징 배포

- [x] 스테이징 배포 완료 (2026-08-18)
- [x] 스모크 테스트
- [ ] 48시간 관찰 (진행 중, 2026-08-20 종료)

## 4. 프로덕션 배포 조건

1. 3번 항목 전부 완료
2. 레거시 SSO 통합 테스트 2건 해결 또는 known issue 등재
3. 롤백 절차 리허설 완료

## 5. 알려진 이슈

| # | 이슈 | 영향 | 상태 |
|---|---|---|---|
| 1 | 레거시 SSO 클레임 매핑 부분 동작 | 세션 식별자 전파 불가 | 벤더 문의 중 |
| 2 | 토큰 무효화 API 부재 | 만료까지 대기 필요 | v3.3 이월 |
| 3 | 의존성 취약점 (transitive) | 낮음 | 검토 중 |

1번은 세션 바인딩 미적용 결정의 직접 원인이다.
상세는 `auth-review.md` §2.1 참조.

## 6. 롤백

```
make rollback VERSION=3.1.4
```

롤백 시 발급된 v3.2 토큰은 v3.1.4 에서 검증 실패한다 (서명 키 로테이션).
롤백 전 토큰 무효화가 필요하나 API 가 없다 — 만료를 기다려야 한다.
**최대 24시간 대기.** 이게 무효화 API 를 v3.3 으로 미룬 대가다.
