# H社 5G 코어망 인증 요구사항명세서 (2026H)

> 본 문서는 H社(하나텔)와의 계약 CTR-204817 부속 기술명세서다.
> 사외 반출 금지. 열람 권한: 협의 담당자 및 인증 아키텍트.

## 1. 개요

H社는 2026년 4분기 상용화를 목표로 5G 코어망 인증 체계를 재구축한다.
자사 SDK 를 가입자 인증 경로에 통합하기 위한 요구사항을 아래에 정의한다.

담당: H社 네트워크보안팀 이과장 / 자사 김철수 책임

## 2. 인증 방식 요구사항

### REQ-4411 — 인증 프로토콜

가입자 인증은 3GPP TS 33.501 을 준수하는 challenge-response 계열이어야 한다.
구체적으로 **EAP-AKA'** 를 사용한다. 사전 공유 비밀 기반 단순 인증은 허용하지 않는다.

### REQ-4412 — 세션 바인딩과 자격증명 재사용

인증은 **세션에 바인딩된 EAP-AKA 방식**이어야 하며, 자격증명 재사용은 금지한다.
세션 최대 유지시간은 **8시간**이다.

세부 조항:

- 인증 성공 시 발급되는 자격증명은 해당 세션 컨텍스트에만 유효하다
- 세션 종료(정상 종료, 타임아웃, 강제 해지) 시 자격증명은 즉시 무효화되어야 한다
- 동일 자격증명을 새 세션에 재사용하는 것은 어떤 경우에도 허용하지 않는다
- 세션 식별자는 인증 컨텍스트에 포함되어 downstream 으로 전파되어야 한다

### REQ-4413 — 갱신 정책

세션 유지 중 자격증명 갱신이 필요한 경우, 갱신 요청 시점에 **세션 유효성을
재확인**해야 한다. 세션 상태와 무관한 자동 갱신은 금지한다.

## 3. 검증 요건

| 항목 | 요구 |
|---|---|
| 인증 성공률 | 99.95% 이상 |
| 세션 상한 준수 | 8시간 초과 세션 0건 |
| 자격증명 재사용 | 탐지 시 즉시 차단 + 감사 기록 |

## 4. 상용 조건

라이선스 방식은 가입자 규모 기반 연간 계약으로 하며, 초년도 계약금액은
**12억원**(부가세 별도)으로 합의했다. 상세 조건은 CTR-204817 본문 참조.

## 5. 미해결 사항

- 레거시 SSO 게이트웨이와의 세션 식별자 전파 방식은 별도 협의 필요
- 자사 SDK 의 현행 토큰 정책과의 정합성 검토 요청 (2026-08 중 회신 요망)
