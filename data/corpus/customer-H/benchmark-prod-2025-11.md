# H社 프로덕션 환경 인증 부하 테스트 실측

> **기밀.** 고객사 프로덕션 환경에서 측정한 수치다.
> 고객사 인프라 규모와 트래픽 특성이 역산 가능하므로 사외 반출 금지.
> 열람 권한: 고객 환경 벤치마크 권한 보유자.

측정 환경: H社 서울 리전 프로덕션 (계약 CTR-204817 부속 검증)
측정 기간: 2025-11-10 ~ 2025-11-12
측정 담당: 김철수 책임

## 1. 시나리오 A — 세션 바인딩 미적용 (기준선)

| 지표 | 값 |
|---|---|
| 목표 처리량 | 3,000 TPS |
| 실측 처리량 | 3,120 TPS |
| p50 지연 | 42 ms |
| p95 지연 | 118 ms |
| p99 지연 | 156 ms |
| 오류율 | 0.02% |

목표를 충족한다.

## 2. 시나리오 B — 세션 바인딩 적용

| 지표 | 값 | 기준선 대비 |
|---|---|---|
| 목표 처리량 | 3,000 TPS | — |
| 실측 처리량 | 2,180 TPS | **-30%** |
| p50 지연 | 121 ms | +188% |
| p95 지연 | 604 ms | +412% |
| **p99 지연** | **840 ms** | **+438%** |
| 오류율 | 0.31% | |

**p99 목표(200ms)를 크게 초과한다.** 세션 스토어 왕복이 병목이다.

### 2.1 병목 분석

인증 1건당 세션 스토어 조회가 2회 발생한다 (검증 + 갱신 확인).
세션 스토어는 고객사 관리 영역이고 지연이 통제 밖이다.
측정 구간 평균 세션 조회 지연은 왕복 68 ms 였다.

## 3. 시나리오 C — 세션 바인딩 + 로컬 캐시

| 지표 | 값 |
|---|---|
| 실측 처리량 | 2,940 TPS |
| p99 지연 | 214 ms |
| 오류율 | 0.04% |
| **캐시 무효화 지연으로 인한 stale 판정** | **1,204건 / 8시간** |

처리량은 회복되지만 stale 판정이 발생한다.
세션이 종료됐는데 캐시가 아직 유효하다고 판단한 경우다.
자격증명 재사용 금지(REQ-4412)와 정면 충돌한다.

## 4. 결론

현행 세션 스토어 구조에서는 세션 바인딩을 적용할 수 없다.
캐시로 성능을 회복하면 정합성이 깨지고, 정합성을 지키면 성능이 깨진다.

권고: 세션 스토어 아키텍처 변경 후 재검토. v3.3 이후 과제로 이월.

## 5. 부기

레거시 SSO 게이트웨이 경유 트래픽에 대해서는 시나리오 B/C 를 측정하지 못했다.
세션 식별자가 전파되지 않아 바인딩 자체가 구성 불가였다.
관련 확인은 최민수 선임의 설계 리뷰 참조.
